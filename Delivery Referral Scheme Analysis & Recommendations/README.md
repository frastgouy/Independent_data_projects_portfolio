README
Assessing the effectiveness of a food delivery company’s Referral scheme.

CONTEXT
You are given data on the referral scheme for riders of a food delivery company.

Based off of this data you are to give a presentation where you are answering:
How has the referral scheme performed, especially against other channels?
Has the referral scheme been successful?
Are there any important factors to consider for changes to the scheme?

TOOLS USED
Python (Pandas/NumPy)
PowerPoint
Tableau

MY ROLE
Independently designed analytical methodology
Defined success framework / KPIs
Cleaned and prepared the data for analysis
Conducted exploratory and comparative analysis
Produced strategic recommendations and presentation

THE DATA
Rider ID – a unique rider identifier
Location – the city the rider applied in
Application_date – the date the rider applied to work
Application_approved_date – the date that the rider application was approved
First_work_date – the date of the rider’s first shift
Acquisition_channel – the last touch marketing channel recorded for the rider/applicant
Vehicle_type – the type of vehicle the rider uses
Days_since_acquisition – the number of days passed since first_work_date
Hours_worked_cumulative – the cumulative number of hours worked by the rider to date
Orders_delivered_cumulative – the cumulative number of orders delivered by the rider to date
Throughput_cumulative: The cumulative throughput (orders/hour) of the rider to date
Referrals_cumulative – The cumulative number of referrals made by that rider to date
Successful_referrals_cumulative – the cumulative number of successful referrals made by that rider to date
